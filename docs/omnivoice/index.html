Podešavanja

Do 90 slova/brojeva ide na tvoj UM790 Pro preko Tailscale-a. Preko 90 ide direktno na Modal. Ako LOCAL nije dostupan, zahtev automatski pada na Modal.

Otvaraj ovu aplikaciju preko GitHub Pages linka. Kada je kućni PC dostupan preko Tailscale-a, kratki zahtevi koriste LOCAL; kada nije dostupan, aplikacija ostaje otvorena i automatski koristi Modal. Aplikacija se kešira i za offline pokretanje interfejsa.
Routing: broje se samo A-Z, a-z, ŠĆČŽĐ, šćčžđ i 0-9. 0–90 → LOCAL. 91+ → MODAL. Ako LOCAL health check ne prođe ili lokalno generisanje vrati grešku, aplikacija automatski pokušava Modal.
